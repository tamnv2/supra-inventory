## Source-proven mechanism and consumption estimates
- `D167SkuCoordinator.Queue()` sets a 15-min timer after failure, yet browser readiness/HA events call `OnPrimaryOrWmsReady()` -> `Queue()` immediately without honoring `nextRetry`; repeated `service.Schedule(day)` calls consume Gateway attempts. Compare `Program.cs` after-hours status refresh; >1,000 SKU failures at least across existing D168 notes and current Agent archives. These events are logs of failed attempts and **must not be counted automatically as Google URL Fetch calls**.
- Each ordinary authenticated `d167_sku_sync` gateway request performs `validateIdToken_` `UrlFetchApp.fetch` to Identity Toolkit and `proxyD167SkuRequest_` `UrlFetchApp.fetch` to Worker: normally 2 URL Fetch calls, unless it fails before the second. Thus ~39 × 2 = **at most about 78** successful-path fetch requests for the identified 12:35–12:45 burst, subject to duplicate archive evidence and early failures.
- `get_firestore_usage` normal single authenticated request uses 1 URL Fetch for auth, plus **13** Monitoring requests on a shared 15-minute CacheService miss (`fetchAll`); cache hits avoid Monitoring calls. If it rebuilt its cache continuously through first 12h45, roughly <=52 * 13 = **676** Monitoring requests for one shared cache; actual may be less if tab is not open, greater with atypical cache expiry/failure/cross-deployment effects. That *normal design* plus identified short SKU burst is **far below 20,000** daily quota; not enough evidence to allocate 20k to SKU or Usage.
- Registered Beta Agent Operations Gateway `execute_as=OWNER` shares the executing owner's Apps Script per-user UrlFetch quota. Any OTHER eligible Apps Script executed as that same Google identity also draws on that account's per-user allotment; whether such scripts actually ran is unverified and out-of-scope resources must not be inspected without scope authority.
- Google official documentation: consumer **20,000/day**, Workspace **100,000/day**, per user, reset **24 hours after first request**, so current local VN calendar day ≠ verified Google quota window. Do **not** assert the Owner has Workspace tier or know first request timestamp. Reference https://developers.google.com/apps-script/guides/services/quotas .
